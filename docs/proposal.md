# 网页文章翻译（Chrome 扩展）需求文档

> 版本：v0.1 ｜ 状态：草稿
> 产品定位：一键提译为中文，并精美格式化展示的 Chrome 浏览器扩展（Manifest V3）。

## 1. 背景与目标取英文网页文章正文，调用 AI 大模型翻

### 1.1 背景
- 英文技术博客、论文、资讯等网页内容阅读成本高。
- 现有网页翻译工具多为「全页译文覆盖」或逐句对照，交互重、格式差、无法聚焦正文。
- 用户希望只针对**文章正文**做高质量的 AI 翻译，并能沉浸式阅读译文。

### 1.2 目标
1. 点击扩展图标即可打开翻译侧边栏（Side Panel）。
2. 自动提取当前标签页的网页文章正文（标题 + 段落）。
3. 调用 AI 大模型把正文翻译为中文，保留段落结构与基本格式。
4. 在侧边栏中分状态展示流程（初始 / 提取中 / 翻译中 / 成功 / 失败），成功态支持中英对照阅读。
5. 提供可配置项（模型、API Key、目标语言、对照模式）并持久化。

## 2. 用户画像
- 英文技术文章读者（开发、科研、资讯）。
- 需要「先懂大意、再精读原文」的双语阅读者。

## 3. 功能需求

### 3.1 核心流程
```
点击图标 → 打开侧边栏(空态) → 用户点击「翻译本页」
→ 提取正文(提取中) → 调用模型翻译(翻译中) → 展示对照结果(成功)
                                      ↘ 任一步骤异常 → 失败态(错误提示/重试)
```

### 3.2 功能清单

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| F1 | 图标打开侧边栏 | 点击扩展图标直接弹出 Side Panel | P0 |
| F2 | 正文提取 | 读取当前标签页文章正文（标题/作者/段落/图片保留） | P0 |
| F3 | AI 翻译 | 调用大模型翻译，输出结构化的中英对照内容 | P0 |
| F4 | 结果展示 | 支持「译文优先」「中英对照」「仅原文」模式 | P0 |
| F5 | 状态反馈 | 初始/提取中/翻译中/成功/失败 五种视图切换 | P0 |
| F6 | 设置 | 模型选择、API Key、提示词、目标语言配置并存储 | P1 |
| F7 | 复制/导出 | 一键复制译文，导出 Markdown | P2 |

### 3.3 非功能需求
- 性能：正文提取在页面上下文完成，翻译过程异步、不卡顿页面。
- 隐私：翻译请求只发送被提取的正文与当前 URL，不上传历史；API Key 仅存本地（`chrome.storage.local`）。
- 兼容：Chrome MV3；依赖 `sidePanel`、`storage`、`scripting` 等权限。
- 可维护：模块化分层（提取 / 翻译适配器 / UI 状态机），便于接入多家模型。

## 4. 边界与非目标
- 不做网页 DOM 原位翻译覆盖。
- 不处理整页非文章型页面（如后台系统、登录页），无正文时给出提示。
- 不内置模型账号体系，模型能力由用户自带 Key 或本地网关提供。

## 5. 验收口径
- 首次点击图标即可展开侧边栏（无需额外点击）。
- 在常见英文文章页（博客 / 新闻 / 文档站）可稳定提取正文。
- 五种 UI 状态切换流畅，成功态译文段落结构完整、可读。
