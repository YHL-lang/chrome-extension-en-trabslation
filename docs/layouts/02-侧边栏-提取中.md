# 02 侧边栏 · 提取中（LoadingView）

## 功能
点击「一键翻译本页」后，正在提取当前页面文章正文（Readability + turndown）。

## 页面布局

```
┌────────────────────────────────┐
│ 网页文章翻译               ⚙  │  ← TopBar
├────────────────────────────────┤
│                                │
│                                │
│             ◐                  │
│          加载中…               │
│                                │
│       正在提取文章正文…         │
│                                │
│                                │
│                                │
├────────────────────────────────┤
│           v0.1.0              │  ← Footer
└────────────────────────────────┘
```

## 模块说明

### TopBar（共享）
- 同初始态。

### 主内容区
- 加载指示（spinner）。
- 提示文案「正在提取文章正文…」。

### Footer（共享）
- 显示版本号。

## 实现步骤
1. 创建 `LoadingView` 组件。
2. 由状态机在 `loading` 状态渲染。
3. 提取完成自动进入 `translating`；失败进入 `error`。
