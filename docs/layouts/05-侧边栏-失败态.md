# 05 侧边栏 · 失败态（ErrorView）

## 功能
提取或翻译任一步骤异常时的提示页面，提供重试。

## 页面布局

```
┌────────────────────────────────┐
│ 网页文章翻译               ⚙  │  ← TopBar
├────────────────────────────────┤
│                                │
│                                │
│              ⚠                │
│       提取失败 / 翻译失败        │
│       原因：未识别到正文         │  ← 错误信息
│                                │
│   ┌────────────────────────┐   │
│   │          重试          │   │  ← 重试按钮
│   └────────────────────────┘   │
│                                │
│                                │
├────────────────────────────────┤
│           v0.1.0              │  ← Footer
└────────────────────────────────┘
```

## 模块说明

### TopBar（共享）
- 同初始态。

### 主内容区
- 错误图标（⚠）。
- 错误标题与具体原因（如「未识别到正文」「翻译超时」）。

### 重试按钮
- 点击后重新进入 `loading`（重新提取与翻译）。

### Footer（共享）
- 显示版本号。

## 实现步骤
1. 创建 `ErrorView` 组件。
2. 接收并展示错误原因。
3. 绑定「重试」事件，重置状态机进入 `loading`。
