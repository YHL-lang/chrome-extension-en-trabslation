# 03 侧边栏 · 翻译中（TranslatingView）

## 功能
正文提取完成后，正在调用 AI 模型（Qwen）流式翻译，并实时打字机预览。

## 页面布局

```
┌────────────────────────────────┐
│ 网页文章翻译               ⚙  │  ← TopBar
├────────────────────────────────┤
│ # 文章标题                     │  ← 元数据头部（标题）
├────────────────────────────────┤
│                                │
│             ◐                  │
│       正在调用 AI 模型…         │
│                                │
│   ┌────────────────────────┐   │
│   │ 译文预览（打字机）…      │   │  ← 流式预览区
│   │ 这是第一段翻译内容……     │   │
│   └────────────────────────┘   │
│                                │
│                                │
├────────────────────────────────┤
│           v0.1.0              │  ← Footer
└────────────────────────────────┘
```

## 模块说明

### TopBar（共享）
- 同初始态。

### 元数据头部
- 展示已提取的文章标题，让用户确认翻译对象。

### 主内容区
- 加载指示 + 「正在调用 AI 模型…」。
- 流式预览区：随分片累积动态显示译文（打字机效果）。

### Footer（共享）
- 显示版本号。

## 实现步骤
1. 创建 `TranslatingView` 组件。
2. 通过 `Port` 接收 background 转发的流式分片并累积。
3. 翻译完成进入 `success`；异常进入 `error`。
