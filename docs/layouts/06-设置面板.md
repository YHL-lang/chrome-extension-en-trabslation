# 06 设置面板（SettingsPanel）

## 功能
配置模型服务与翻译参数，持久化到 `chrome.storage.local`。

## 页面布局

```
┌────────────────────────────────┐
│ ← 设置                        │  ← TopBar（返回）
├────────────────────────────────┤
│ 模型服务                       │
│ baseURL  [__________________] │
│ 模型     [qwen-plus        ▾] │
│ API Key  [__________________] │
│ 提示词   [__________________] │
│ 目标语言 [中文            ▾] │
│ 默认展示 [译文优先        ▾] │
│                                │
│   ┌────────────────────────┐   │
│   │        保存设置         │   │  ← 保存按钮
│   └────────────────────────┘   │
│                                │
├────────────────────────────────┤
└────────────────────────────────┘
```

## 模块说明

### TopBar
- 左侧「← 设置」返回按钮，点击回到初始态。

### 配置表单
| 字段 | 说明 | 默认 |
| --- | --- | --- |
| baseURL | 模型服务 OpenAI 兼容端点 | 指向 Qwen |
| 模型 | 模型名 | `qwen-plus` |
| API Key | 调用密钥（仅本地存储） | 空 |
| 提示词 | 翻译提示词 | 默认中文翻译提示 |
| 目标语言 | 翻译目标语言 | 中文 |
| 默认展示 | 默认展示模式 | 译文优先 |

### 保存按钮
- 点击后将配置写入 `chrome.storage.local` 并返回。

## 实现步骤
1. 创建 `SettingsPanel` 组件与配置表单。
2. 表单读写 `lib/storage` 封装的 `chrome.storage.local`。
3. 绑定保存与返回事件。
