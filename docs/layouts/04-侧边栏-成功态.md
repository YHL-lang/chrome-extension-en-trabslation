# 04 侧边栏 · 成功态（SuccessView）

## 功能
翻译完成后展示结果，支持「译文优先 / 中英对照 / 仅原文」三种展示模式，并可一键复制、下载 Markdown。

## 页面布局（译文优先）

```
┌────────────────────────────────┐
│ 网页文章翻译               ⚙  │  ← TopBar
├────────────────────────────────┤
│ # 文章标题                     │
│ > 作者：xxx                    │  ← 元数据头部
│ > 原文链接：https://…          │
├────────────────────────────────┤
│ [译文优先]  中英对照  仅原文    │  ← 展示模式切换
├────────────────────────────────┤
│                                │
│  ## 段落标题                   │
│  译文正文……                    │  ← md-wx 渲染区
│                                │
│  ![图片](src)                  │
│                                │
│                                │
├────────────────────────────────┤
│  [复制]         [下载 Markdown] │  ← 底部操作
└────────────────────────────────┘
```

│  …              …              │  ← 左右两列 md-wx
│                                │

└────────────────────────────────┘
```

```

## 模块说明

### TopBar（共享）
- 同初始态。

### 元数据头部
- 标题（`#`）、作者（`> 作者`）、原文链接（`> 原文链接`）。
- 内容来自提取层结构化数据。

### 展示模式切换
- 三个标签：译文优先 / 中英对照 / 仅原文。
- 对应设计文档 §5.2 的 `displayMode` 映射，仅作用于成功态。

### 正文渲染区（md-wx）
- 译文优先 / 仅原文：单个 `MarkdownRenderer`。
- 中英对照：左右两个 `MarkdownRenderer` 并排。

### 底部操作
- 「复制」：一键复制当前渲染内容。
- 「下载 Markdown」：将结果导出为 `.md` 文件（核心动作）。

## 实现步骤
1. 创建 `SuccessView` 组件，接入 `MarkdownRenderer`。
2. 实现展示模式切换（译文优先 / 中英对照 / 仅原文）。
3. 实现「复制」与「下载 Markdown」。
4. 结果写入 `chrome.storage.local`，下次打开恢复。
