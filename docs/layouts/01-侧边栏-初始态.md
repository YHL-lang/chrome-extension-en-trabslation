# 01 侧边栏 · 初始态（EmptyView）

## 功能
打开侧边栏时的默认页面。核心动作是「一键翻译本页」。

## 页面布局

```
┌────────────────────────────────┐
│ 网页文章翻译               ⚙  │  ← TopBar
├────────────────────────────────┤
│                                │
│                                │
│           （ 文章插图 ）        │
│                                │
│        提取当前网页文章         │
│        并一键翻译为中文         │
│                                │
│   ┌────────────────────────┐   │
│   │      一键翻译本页        │   │  ← 主按钮
│   └────────────────────────┘   │
│                                │
│                                │
├────────────────────────────────┤
│            v0.1.0              │  ← Footer
└────────────────────────────────┘
```

## 模块说明

### TopBar（共享）
- 左侧标题「网页文章翻译」。
- 右侧 ⚙ 图标，点击进入设置面板。

### 主内容区
- 插图/图标：示意用途，非必需。
- 说明文案：提示「提取当前网页文章，并一键翻译为中文」。

### 主按钮「一键翻译本页」
- 触发核心流程：提取正文 → AI 翻译。
- 主色、通栏、圆角，突出为页面焦点。

### Footer（共享）
- 显示版本号与当前状态。

## 实现步骤
1. 创建 `EmptyView` 组件。
2. 接入共享 `TopBar` / `Footer`。
3. 绑定「一键翻译本页」点击事件，触发状态机进入 `loading`。
