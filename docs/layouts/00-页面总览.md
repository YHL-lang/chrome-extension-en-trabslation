# 页面总览与实现步骤

> 依据 `docs/proposal.md` 与 `docs/design.md`。插件 UI 为 Chrome Side Panel（侧边栏），按状态划分为以下「页面」。设计简约，突出「一键翻译」与「下载」。

## 1. 页面清单

| 序号 | 页面 | 文件 | 职责 |
| --- | --- | --- | --- |
| 01 | 初始态 | [01-侧边栏-初始态.md](01-侧边栏-初始态.md) | 打开面板后的空态，提供「一键翻译本页」 |
| 02 | 提取中 | [02-侧边栏-提取中.md](02-侧边栏-提取中.md) | 正在提取文章正文 |
| 03 | 翻译中 | [03-侧边栏-翻译中.md](03-侧边栏-翻译中.md) | 正在调用 AI 流式翻译 |
| 04 | 成功态 | [04-侧边栏-成功态.md](04-侧边栏-成功态.md) | 展示译文/原文，支持下载 Markdown |

| 06 | 设置面板 | [06-设置面板.md](06-设置面板.md) | 模型 / Key / 提示词 / 目标语言 / 展示模式配置 |

## 2. 共享模块

- **TopBar**：侧边栏顶栏，左「网页文章翻译」标题，右 ⚙ 设置入口。
- **Footer**：侧边栏底栏，显示版本号与状态。

## 3. 实现步骤总规划（按模块）

1. **工程初始化**：WXT + React + TS，安装 `md-wx`、`openai`、`@mozilla/readability`、`turndown`。
2. **侧边栏框架**：App 状态机 + TopBar / Footer 共享组件。
3. **初始态页面**：EmptyView。
4. **过程态页面**：提取中 / 翻译中 / 失败态。
5. **成功态页面**：md-wx 渲染 + 三种展示模式 + 复制 / 下载。
6. **设置面板**：配置项表单与本地持久化。
7. **端到端联调**：流式打字机、下载、打包验证。
